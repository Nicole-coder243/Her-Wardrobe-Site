# Her Wardrobe Site 👗

A conceptual website design/mockup for **Her Wardrobe**—a fashion business that celebrates every moment as a statement.

## 🌸 About

**Her Wardrobe** is a conceptual business idea:  
A fashion destination where every outfit is a moment, and every choice is a statement.  
This mockup website showcases how Her Wardrobe could present its brand, style, and services in a modern, inspiring way.

## 🛠️ Tech Stack

- **HTML** (61.3%)
- **CSS** (38.7%)

## ✨ Features

- **Homepage:** Welcoming layout with highlights and visuals
- **About:** Information about the brand and its vision
- **Categories:** Browse different fashion and wardrobe sections
- **Contact:** Easy way for visitors to get in touch
- **FAQ:** Answers to common questions but just questions that may be asked about the design and idea

## 🚀 Usage

1. Clone the repository:
    ```bash
    git clone https://github.com/Nicole-coder243/Her-Wardrobe-Site.git
    cd Her-Wardrobe-Site
    ```
2. Open `index.html` in your browser to view the mockup.
